Instellingen | Voorkeursinstellingen...

Deze optie opent een scherm waarin de voorkeursinstellingen van het programma kunnen worden opgegeven. De instellingen worden in de programmamap opgeslagen in het bestand GL.INI.

 

Bestandslokaties

StandaardcatalogusWeergave van de folder waar de standaardcatalogus staat.
BedrijfscatalogusWeergave van de folder waar de bedrijfscatalogus staat. Deze folder kan met de knop [...] worden gewijzigd. Als er geen schrijfrechten aanwezig zijn voor de betreffende programmamap zal hiervan melding worden gemaakt.
ProjectenWeergave van de folder die standaard wordt geselecteerd als wordt gekozen voor Bestand | Openen (sneltoets <ctrl>+<o>), Bestand | Opslaan (sneltoets <ctrl>+<s>) of Bestand | Opslaan als.... Deze plaats kan met de knop [...] worden gewijzigd.  Als er geen schrijfrechten aanwezig zijn voor de betreffende programmafolder zal hiervan melding worden gemaakt.

 

Veiligheidscorrectie

Invoervelden voor veiligheidscorrecties. De ingevoerde veiligheidscorrectie is minimaal 0 dB en kan maximaal 100 dB bedragen. Op ieder element kunnen veiligheidscorrecties worden toegepast. De hier ingestelde veiligheidscorrectie wordt standaard ingevoerd als een nieuw element op een tabblad Vlak wordt toegevoegd. De veiligheidscorrectie kan per element op het tabblad Cveilig weer worden gewijzigd.

 

Fysische eigenschappen

De voortplantingssnelheid van geluid in lucht is afhankelijk van de temperatuur. Standaard wordt met een temperatuur van 0 °C gerekend. De voortplantingssnelheid beïnvloed de geluiddemping in de ruimte (in het programma opgenomen in de vorm van de nagalmtijd).

 

Algemeen

Geluidwering gevels maakt automatisch een backup van het geopende project. De standaard interval waarin deze backup wordt gemaakt bedraagt 20 minuten. Indien de automatische backup vaker of minder vaak dient te worden gemaakt, kan hier de interval worden aangepast. De opgegeven waarde wordt in het Windows register opgeslagen. Indien als waarde nul (0) wordt ingevuld, worden er geen automatische backups van het project gemaakt.

 

Reflectiecorrectie Cr

Het genormaliseerde gevelgeluidsniveauverschil D2m,nT wordt gemeten inclusief reflecties. Voor de berekening van het binnenniveau mogen deze echter niet worden meegenomen. Deze waarde kan niet worden aangepast.

Invoergegevens, Berekening of Subsidie

Indien in dit menu één van de drie mogelijkheden (Invoergegevens, Berekening of Subsidie) wordt geselecteerd dan verschijnt de bijbehorende tab steeds als eerste bij het doorlopen van de boom. Indien het geselecteerde tabblad niet voorkomt bij het betreffende niveau wordt de instelling ongedaan gemaakt. Als er geen instelling is geselecteerd, wordt altijd het eerste tabblad weergegeven.
